# esp32-FixedHorizon

Horizon Controller - это проект для ESP32, предназначенный для управления сервоприводом для стабилизации камеры (горизонтального угла) в беспилотных летательных аппаратах (БПЛА). Проект позволяет точно управлять положением камеры в реальном времени с помощью данных MAVLink от полетника.

Основные особенности
1. Управление сервоприводом
Точное управление горизонтальным углом поворота камеры
Поддержка серво-приводов с диапазоном 500-2500 мкс
Возможность настройки центрального положения, максимального угла и диапазона PWM
2. MAVLink интерфейс
Получение данных о姿态 (pitch, roll, yaw) от полетника
Получение данных о RC-каналах для дополнительного управления
Потоковая передача данных вместо постоянных запросов (оптимизация нагрузки на полетник)
3. Гибкая настройка через веб-интерфейс
Настройка канала RC для управления горизонтом (1-18 канал)
Настройка центрального положения сервопривода
Настройка максимального угла поворота
Настройка диапазона PWM (min/max)
Регулировка множителя угла поворота для точной настройки чувствительности
Переключение направления вращения сервопривода
Настройка скорости передачи MAVLink
4. Дополнительные возможности
Сохранение настроек в EEPROM
Встроенный веб-сервер для управления
Статистика работы системы
Обнаружение и обработка ошибок MAVLink
